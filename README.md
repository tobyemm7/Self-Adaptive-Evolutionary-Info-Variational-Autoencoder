Code packages used to produce the results of the Self Adaptive Evolutionary Info Variational Autoencoder model and comparisons.
The code runs in the Jupyter Notebook environemnt of Google Colab. It is recommended to use the Colab Pro package to run on the available GPUs.
The paper associated with this work can be found at https://www.mdpi.com/2922684, please cite the paper if you use this code. Thanks :)
